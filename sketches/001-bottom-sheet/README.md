## 底部抽屉

小按钮默认收起；展开后横向利用屏幕宽度，适合单手切换。

- 视觉沿用 X 的黑白与蓝色，系统字体。
- 小按钮自由拖动、记住位置；面板标题向下滑动收起。
- 常态面板最多占网页视口高度 46%，按 ↕ 可主动展开到 65%。
- 点击联系人直接插入，自动收起面板；支持多选。
- 本人 Following 页面和进度名单均演示未回关高亮：仅我已关注、对方未回关时显示浅红底、左色条和文字；互关不高亮。进度开关可同时去色。
- 模拟键盘弹出后缩短抽屉，为输入文字留出上方区域；多选插入按钮固定在抽屉内，联系人列表单独滚动。
- 优势：容易点，阅读宽度够，底部操作集中。
- 取舍：展开时横向覆盖整个底部；内容多时需要滚动。

根目录预览器按 Chrome DevTools 设备预设（2026-06-16，commit `f1fbee878f8958db80c0d421888ad49e9b03b790`）提供主流 Pixel/iPhone 与安卓窄屏 CSS 整屏尺寸。网页实际视口扣除可切换的系统栏、Firefox 栏与手势区；iframe 保持所选完整宽度，外层只做等比缩放。浏览器栏占位为演示值，真实高度随系统和浏览器状态变化。
