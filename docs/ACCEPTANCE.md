- 运行源码语法与双清单合同检查通过。

- Windows Firefox **158.0.1** 已通过 `web-ext run` 在临时全新配置中成功安装；此项是桌面加载冒烟检查，完整功能联测运行于 Chromium，不能替代 Android 真机验收。
